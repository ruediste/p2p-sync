JReact is declarative UI framework backed by Swing and Java2D. It brings React's component model 
and web-standard styling and layout model (Flexbox) directly to Java, completely bypassing web views 
and HTML/JS bridges.

todo: Advantages: 
- no separate language
- no separate build system
- no client/server issues (requests, serialization, data transfer)
- no web view overhead
- small footprint
- leverages existing Java ecosystem
- can use existing Swing components
